Twin Bishkek · страница для менторов

Горы видно?

Цифровой двойник Бишкека: меняешь городское решение — автопарк, стройку, новую дорогу, посадку деревьев — и сразу видишь, что станет с пробками, воздухом и комфортом района.

Открыть демо →симулятор с картой 2GIS Код на GitHubPython + JS, тесты, данные Презентация13 слайдов, 7 минут · PDF внизу API (Swagger)/simulate, /plan, /live

Бесплатный хостинг: если сайт долго не открывали, первая загрузка занимает около минуты.

Как устроено

Решение→Трафик (BPR, 919 участков улиц)→PM2.5 по 473 сотам→AQI (EPA)→Комфорт района

Одна и та же модель написана дважды: на Python (сервер FastAPI) и на JavaScript (сайт работает и без сервера). Результаты совпадают до 10⁻¹³. Поверх модели — текстовый «Разбор от модели»: объясняет причины и предлагает исправления, каждое сначала прогоняя через модель.

Запустить у себя

git clone https://github.com/okenawka-jpg/Twin-bishkek
cd Twin-bishkek
python -m venv venv
venv\Scripts\activate
pip install -e ".[api,dev]"
pytest
uvicorn twin_bishkek.api:app --port 8000

Сайт откроется на localhost:8000, Swagger — на /docs.

Карта 2GIS: перед запуском задать ключ TWINGIS_MAPGL_KEY. Без сервера сайт можно открыть двойным кликом по site/index.html — посчитает встроенная JS-модель.

Подробно: README_BACKEND.md · источники и ограничения
